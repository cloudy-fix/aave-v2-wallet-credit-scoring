# Aave V2 Wallet Credit Scoring

Python project for scoring Aave V2 wallet behavior using DeFi transaction patterns and credit-risk style analysis.

## Interview Angle

This project is useful for explaining data-driven scoring logic, feature thinking, and API/data processing in a financial technology context. It can also support conversations about risk modeling and explainable scoring.

## What To Discuss

- Wallet activity features used for scoring
- Borrowing, repayment, liquidation, and transaction behavior signals
- Scoring logic and explainability
- Data cleaning and transformation
- How model outputs could be validated

## Skills Demonstrated

- Python
- DeFi data analysis
- Wallet behavior scoring
- Risk scoring concepts
- API/data workflow practice

## Suggested Next Improvements

- Add a sample wallet scoring report.
- Add a clear setup and run command once dependencies are stable.
- Add validation notes explaining how scores should be interpreted.
